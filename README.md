# 🚀 VyaparaMitra

> **An AI-Powered Business Management Platform for Small & Medium Businesses (SMBs)**

VyaparaMitra is a modern web application that helps small businesses manage their daily operations through a single dashboard. It combines inventory management, customer management, sales tracking, invoicing, analytics, reports, and AI-powered assistance to simplify business operations.

---

# 📖 Description

Managing a small business manually can be time-consuming and error-prone. Shop owners often use notebooks or multiple applications to manage products, customers, inventory, and sales.

VyaparaMitra provides a centralized platform where business owners can manage their operations efficiently while leveraging AI for smarter decision-making.

---

# ❗ Problem Statement

Small and medium businesses face challenges such as:

- Manual inventory management
- Difficulty tracking sales
- Poor customer record management
- Time-consuming invoice generation
- Lack of business insights
- Limited access to AI-powered assistance

VyaparaMitra addresses these challenges by providing an all-in-one AI-powered business management solution.

---

# 💡 Solution

VyaparaMitra offers a unified dashboard that enables businesses to:

- Manage products
- Track inventory
- Manage customers
- Record sales
- Generate invoices
- View reports
- Analyze business performance
- Use AI Copilot for assistance
- Interact using voice commands

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/Vyapara-Mitra.git
```

Go into the project folder

```bash
cd Vyapara-Mitra
```

Install dependencies

```bash
npm install
```

---

# ▶️ Run the Project

Start the development server

```bash
npm run dev
```

Build the project

```bash
npm run build
```

Start the production server

```bash
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file in the root directory and add the required API keys.

Example:

```env
GEMINI_API_KEY=your_api_key
```
